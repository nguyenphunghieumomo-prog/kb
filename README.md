# Sổ tay học tập
Web tĩnh lưu tài liệu theo mục > mục nhỏ. Xem `PROMPT_COPILOT.md` (cách làm việc với Copilot) và `.github/copilot-instructions.md` (luật xử lý tài liệu).

Chạy thử: `python scripts/build_index.py && python -m http.server 8080` rồi mở http://localhost:8080
Đăng: bật Settings > Pages > Source: GitHub Actions, rồi push lên nhánh main.
